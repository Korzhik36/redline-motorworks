# REDLINE MOTORWORKS

**Контрольная работа №2 — «CSS-фреймворки: разработка интерфейса на Bootstrap».**

REDLINE MOTORWORKS — многостраничный учебный сайт вымышленного тюнинг-ателье, специализирующегося на JDM, дрифт-проектах и спортивном тюнинге.

## Страницы проекта

- `index.html` — главная страница, hero-блок, преимущества и избранные проекты.
- `catalog.html` — каталог из шести концептуальных автомобильных проектов, поиск и фильтрация.
- `product.html` — подробная страница проекта Nissan Silvia S15, спецификация и фотогалерея.
- `order.html` — форма заявки с проверкой обязательных полей на стороне браузера.
- `contacts.html` — информация о концепции ателье и accordion с принципами работы.

## Технологии

- HTML5
- CSS3
- Bootstrap 5.3.3 (CDN)
- JavaScript (DOM, события, фильтрация и проверка формы)

## Bootstrap-компоненты

В проекте используются:

- `container`, `row`, `col-*`, `g-*` — адаптивная 12-колоночная сетка;
- `navbar` — общая навигация на всех страницах;
- `card` — карточки автомобильных проектов;
- `btn` — кнопки действий;
- `badge` — метки категорий проектов;
- `alert` — информационные сообщения;
- `modal` — быстрое описание проекта в каталоге;
- `form-control`, `form-select`, `input-group`, `form-check` — элементы формы;
- `carousel` — галерея проекта;
- `accordion` — раскрывающиеся блоки на странице «О нас».

## Самостоятельные доработки

- добавлена отдельная страница «О нас»;
- реализованы поиск и фильтрация каталога по направлению;
- реализовано заполнение модального окна данными выбранной карточки;
- добавлена клиентская проверка формы и сообщение об успешной проверке;
- разработана единая тёмная визуальная тема с фиолетовым акцентом;
- добавлены адаптивные состояния для мобильных экранов;
- добавлены подписи `label`, альтернативные тексты изображений и состояния фокуса.

## Запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в Visual Studio Code.
3. Откройте `index.html` в браузере (удобно через расширение Live Server).
4. Для загрузки Bootstrap и фотографий необходимо подключение к интернету.

## Проверка

- Перейти по всем пунктам навигации.
- Проверить каталог: поиск и фильтр JDM / Drift / Street.
- Открыть быстрое описание проекта в модальном окне.
- Переключить фотографии на странице проекта.
- Заполнить форму заявки и проверить сообщения валидации.
- Проверить отображение на ширине 375 px, 768 px и 1280 px.
