# REDLINE MOTORWORKS

**Контрольная работа №2 — «CSS-фреймворки: разработка интерфейса на Bootstrap».**

REDLINE MOTORWORKS — многостраничный учебный сайт-концепция тюнинг-ателье, посвящённого JDM, дрифту и спортивным автомобильным проектам. Автомобили, цены и комплектации представлены как демонстрационные концепты.

## Страницы проекта

- `index.html` — главная страница: hero-блок, преимущества и избранные проекты.
- `catalog.html` — каталог шести автомобильных проектов с поиском, фильтрацией, карточками и быстрым просмотром.
- `services.html` — страница услуг и направлений работы ателье.
- `product.html` — страница Nissan Silvia S15 (открывается из каталога проектов).
- `skyline.html` — страница Nissan Skyline R34.
- `bmw-e46.html` — страница BMW E46 Coupe.
- `vaz-2107.html` — страница ВАЗ-2107.
- `supra.html` — страница Toyota Supra MK4.
- `mazda-rx7.html` — страница Mazda RX-7 FD.
- `order.html` — форма заявки с клиентской валидацией. Форма демонстрационная и не отправляет данные на сервер.
- `contacts.html` — концепция ателье, accordion с принципами работы и интерактивная Яндекс Карта.

## Технологии

- HTML5;
- CSS3;
- Bootstrap 5.3.3 через CDN;
- JavaScript (DOM, события, поиск и фильтрация каталога, быстрый просмотр, проверка формы);
- Git и GitHub.

## Bootstrap-компоненты

- `container`, `row`, `col-*`, `g-*` — адаптивная 12-колоночная сетка;
- `navbar` — адаптивная навигация в шапке и футере;
- `card` — карточки проектов;
- `btn` — кнопки и ссылки-действия;
- `badge` — метки направлений;
- `alert` — информационные сообщения и результаты проверки формы;
- `modal` — быстрое описание выбранного проекта;
- `form-control`, `form-select`, `input-group`, `form-check` — элементы формы заявки и фильтров;
- `carousel` — галерея фотографий «ДО / ПОСЛЕ» на страницах автомобилей;
- `accordion` — раскрывающиеся блоки на странице «О нас».

## Запуск проекта

1. Клонируйте репозиторий или скачайте проект.
2. Откройте папку проекта в Visual Studio Code.
3. Запустите `index.html` через Live Server.
4. Для загрузки Bootstrap и отображения Яндекс Карты требуется подключение к интернету. Фотографии автомобилей хранятся локально в папке `images/`.

## Проверка

- перейти по ссылкам навигации;
- проверить все шесть карточек каталога и соответствующие страницы;
- проверить поиск и фильтр каталога;
- открыть быстрый просмотр разных карточек и проверить кнопку перехода на страницу выбранного автомобиля;
- переключить фотографии «ДО / ПОСЛЕ»;
- проверить валидацию формы заявки;
- проверить раскрытие accordion и мобильного меню;
- проверить интерактивность Яндекс Карты;
- проверить отображение на ширине 375 px, 768 px и 1280 px.
